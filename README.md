# DYSecondaryConfirmation

抖音点赞、收藏与关注二次确认插件。开启功能后，执行对应操作前会先显示确认弹窗，减少误触；取消操作不会改变当前状态。

## 功能

- 点赞、取消点赞二次确认
- 收藏、取消收藏二次确认
- 关注、取消关注二次确认
- 覆盖播放、搜索、个人主页、评论、列表和直播等常见操作入口
- 三项功能默认关闭，设置修改后立即生效

## 使用

进入「抖音设置 → 二次确认」，按需打开点赞、收藏或关注开关。

## 适配说明

当前仅在抖音 **39.9.0** 上完成测试。其他版本请自行测试；如果出现失效或 BUG，欢迎 Fork 后按实际版本进行修复和优化。

默认注入过滤器匹配可执行文件 `Aweme`，并为官方抖音保留 bundle ID 匹配项。其他分身可按实际可执行文件名或 bundle ID 调整 `DYLike.plist`；过滤器匹配不代表版本兼容，极速版未列为适配目标。

## 手动构建

GitHub Actions 只通过手动运行，不会因 push、Pull Request 或 tag 自动构建。

1. 打开 Actions，选择 `Build DYSecondaryConfirmation`。
2. 点击 `Run workflow`，在 `构建方案` 中选择一个 scheme：`rootful`、`rootless` 或 `roothide`。
3. 运行完成后，在本次工作流的 Artifacts 中下载所选方案的构建包。

每次工作流只构建并上传一个方案。选择 `rootful` 时还会生成 arm64 动态库文件；其他方案只生成对应的安装包。
